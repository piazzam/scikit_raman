# scikit_raman

scikit_raman is an internal research library developed to support the
manipulation, preprocessing, visualization, and analysis of Raman spectral
data through machine-learning and deep-learning workflows.

The library was originally developed as part of a Master's thesis in Computer
Science at the University of Milan-Bicocca and was subsequently extended to
support reproducible experimental pipelines for biomedical Raman spectroscopy.

## Main capabilities

- Loading and representing Raman spectral datasets
- Spectral preprocessing and normalization
- Dimensionality reduction
- Data augmentation
- Machine-learning and deep-learning experiments
- Subject-aware cross-validation
- Model evaluation and visualization
- YAML-based experiment configuration
- Command-line experiment execution
